# ANTI AI SLOP

This is a critical rule file. The AI must avoid generic AI-generated design patterns.

**FORBIDDEN BY DEFAULT:**
- excessive gradients
- gradient backgrounds
- gradient text
- gradient buttons
- neon colors
- excessive glow
- excessive shadows
- huge shadows
- multiple shadows
- excessive blur
- excessive glassmorphism
- decorative blobs
- random circles
- random floating shapes
- random particles
- excessive cards
- card inside card inside card
- excessive rounded containers
- excessive pills
- excessive badges
- excessive icons
- emoji as UI icons
- excessive animations
- unnecessary parallax
- excessive hover effects
- fake statistics
- fake testimonials
- fake notifications
- fake dashboards
- fake functionality
- unnecessary sections
- unnecessary visual decoration
- generic purple/blue AI aesthetics

**Self-Check:**
If an element exists only to make the design look "cool", question whether it should exist.
