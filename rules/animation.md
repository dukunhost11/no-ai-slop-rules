# ANIMATION

Animations must be purposeful.

**Use animation for:**
- navigation
- transitions
- feedback
- state changes
- loading
- interaction

**Prefer:**
- fast
- smooth
- subtle

**Avoid:**
- bounce
- continuous floating
- spinning decorations
- large zoom
- excessive parallax
- constant motion
- attention-grabbing effects

**Respect:** `prefers-reduced-motion`
