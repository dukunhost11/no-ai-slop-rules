# LIQUID GLASS

Liquid Glass is **DISABLED** by default.
It becomes active only when the user explicitly uses: `/liquid`

When `/liquid` is active:

**ALLOW:**
- translucent surfaces
- backdrop blur
- subtle transparency
- thin borders
- restrained reflections
- layered depth
- Apple-inspired glass surfaces

**DO NOT:**
- make everything glass
- use excessive blur
- use excessive transparency
- use neon
- use rainbow effects
- use excessive glow
- use excessive reflections
- turn every card into glass

Liquid Glass must remain:
subtle, premium, restrained, functional.

Priority:
usability -> hierarchy -> typography -> spacing -> THEN glass effects.

If `/liquid` is not specified:
Do not use Liquid Glass.
