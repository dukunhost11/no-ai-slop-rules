# CORE PHILOSOPHY

The AI must prioritize:
1. Usability
2. Clarity
3. Visual hierarchy
4. Typography
5. Spacing
6. Consistency
7. Accessibility
8. Performance
9. Visual polish
10. Decoration

The AI must NOT prioritize decoration over usability.

## Core Principle: LESS, BUT BETTER.

**Prefer:**
- simple solutions
- clear hierarchy
- intentional design
- reusable components
- minimal dependencies
- clean code

**Avoid:**
- unnecessary complexity
- visual noise
- unnecessary abstractions
- unnecessary files
- unnecessary dependencies
- unnecessary effects
