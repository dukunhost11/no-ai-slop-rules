# UI DESIGN

The UI should be:
- modern
- clean
- minimal
- premium
- precise
- elegant
- intentional

Use Apple-inspired design principles.
*IMPORTANT: Apple-inspired does NOT mean copying Apple's UI.*

**Use principles such as:**
- simplicity
- hierarchy
- restrained visual language
- precise spacing
- strong typography
- subtle borders
- subtle depth
- clear interaction states
- calm interfaces

Every element must have a purpose. 
The AI must ask internally: *"Does this improve usability or hierarchy?"* 
If not, remove it.

## Gradient Policy
Gradients are **DISABLED** by default.
The AI must NOT use gradients unless the user explicitly requests them.

**Forbidden by default:** linear-gradient, radial-gradient, conic-gradient, mesh gradients, aurora gradients, gradient text, gradient buttons.

If the user explicitly requests a gradient:
- Use it only where requested.
- Keep it restrained.
- Do not introduce additional gradients elsewhere.

## Shadow Policy
Avoid heavy shadows.
**Prefer:** subtle border, surface contrast, small elevation, very soft shadow.
**Never create:** huge blur shadows, dark floating shadows, multiple layered shadows.

The UI must still look good without shadows.
