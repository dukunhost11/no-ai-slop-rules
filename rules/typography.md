# TYPOGRAPHY

Typography is a primary design element. The AI must prioritize typography before decorative effects.

- Use a maximum of **2–3 font families** per page unless the user explicitly requests otherwise.

## Recommended Hierarchy:
1. **Display font** (Headings)
2. **Modern sans-serif** (Body text/UI)
3. **Optional decorative/script accent** (Small accents only)

Use decorative fonts sparingly. Never use decorative fonts for long paragraphs.

## Typography Direction
The typography direction is inspired by elegant fonts such as:
*LetterSmith, Texta Narrow, Boho Script, Grota, Darwin, PillowBook, Ashley Brush Script, Ondise, Woolen, Homi Script, Loveton, Sherlock.*

(These names are visual references, not a strict requirement to use all of them. If the exact font is unavailable, choose a visually similar high-quality alternative).

Typography should feel:
- elegant
- modern
- editorial
- human
- premium

**Avoid:** generic typography combinations, random font mixing, too many font families, poor line-height, poor letter spacing, unreadable decorative fonts.
